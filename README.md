Personal website of **Harikrishnan A Ra**, FIDE Grandmaster (2519) and MS Innovation & Entrepreneurship student at the University of Texas at Dallas.

## Deployment

This site is built as a single-page HTML application — no build step required.

### GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://yourusername.github.io/repository-name`

### Custom Domain (optional)

Add a `CNAME` file to the root with your domain:
```
harikrishnanara.com
```
